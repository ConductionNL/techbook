# Techbook

Werkrepo voor het documentatie-handboek van Conduction: het per-repo
docs-contract, de herhaalbare audit en de nulmeting. Het uiteindelijke
portaal (aggregatie van de `/docs` van deelnemende repos) volgt uit de
openspec-changes in dit repo.

  (how-to).
